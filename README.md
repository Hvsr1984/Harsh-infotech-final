# Harsh Infotech — Digital Product Catalog & Showroom

A responsive commercial landing page and digital product catalog for Harsh Infotech, a television and wholesale display distributor based in Jaipur, Rajasthan.

---

## 📌 Overview

**Harsh Infotech** provides customers and wholesale buyers with a fast, mobile-first product catalog showcasing LED TVs, Smart displays, specifications, and direct store contact channels. Designed for fast loading, straightforward navigation, and local search visibility.

---

## ✨ Features

- **Product Showcase:** Clear categorization of displays by size and screen specifications.
- **Mobile-First Layout:** Fast-loading, lightweight responsive design optimized for local consumers.
- **Direct Contact Channels:** Seamless integration for customer inquiries, WhatsApp ordering, and direct owner consultation.
- **SEO & Local Business Optimization:** Tailored metadata and structured schema for local electronic retailer search in Jaipur.

---

## 🛠️ Tech Stack

- **Markup:** HTML5 (Semantic Structure)
- **Styling:** CSS3 & Tailwind Utility Classes
- **Scripting:** Vanilla JavaScript
- **Deployment:** Vercel / GitHub Pages
